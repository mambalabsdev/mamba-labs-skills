# Knowledge Operations

**Write things down so the next person, or the next session, does not start over.**

## Who it is for

Teams working with agents, and anyone whose documentation is a pile.

## The problem

Notes get lost, results documents assert rather than verify, handoffs describe history instead of state, and a knowledge base becomes a flat pile where everything is saved and nothing is findable.

## What is in it

Four disciplines and one system. The write discipline proves a document was stored rather than trusting a success response. The verifier asks the one question that separates a verified claim from an asserted one. The handoff writes state rather than narrative. The classification skill turns a flat pile into a tree with an archive route that goes both ways.
