# Agency Delivery

**Run client work so the first argument is about a written line rather than a memory.**

## Who it is for

Agencies, consultants and fractional operators delivering for other people.

## The problem

Engagements go wrong in the first month, in ways that were knowable in the first week: access was requested late, success was never defined as a number, and the assumptions were never written down.

## What is in it

The pack front loads the questions whose answers change the plan, then keeps the engagement legible: a weekly report that leads with the number against the target in either direction, an attribution audit that ends disputes by refusing to allocate the ambiguous bucket, and a work order format that lets anything be delegated without a follow up conversation.

## Shared context

Every skill in this pack reads `BRAND.md`, `ICP.md` and `VOICE.md` from your
project root where they exist. `brand-context-builder` writes all three from one
interview, and output quality compounds across the pack as those files improve.
